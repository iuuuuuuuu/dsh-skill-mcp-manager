# Agent Note: MCP 连接检测（管理页真握手探活 + lastCheck 落盘）

Status: implemented

## Problem

用户的原话是「没有检测 MCP 链接的功能」。卡片当时只有一个工具数和一个常驻失败标记，两者都回答不了「这个条目现在还连得上吗」：工具快照可能是几个月前的，`connectFailed` 只反映本进程里 eager 注册的那一次尝试。而「连不上」正是用户最需要看见的信息——MCP 配错、密钥过期、本地程序升级、端口变了，症状都一样：AI 调用时才失败，或者干脆一直没人发现。判定必须来自一次真连接，而不是从快照推断。

## Decision

新增 `POST /skill-mcp-manager/mcp/test`（`testMcp`）：用条目自己配置的传输方式走一次真握手（stdio 起子进程 / streamable-http 做 HTTP），再 `tools/list` 取本次实际工具名，条目不变。超时用新配置项 `checkTimeoutMs`（默认 15000，短于 `trialTimeoutMs` 的 30000——这次是人在卡片前等着）。探活客户端在 handler 返回前一定 `close()`，不进 `liveSessions`，不影响任何会话实例。

三条边界是刻意的：

1. **失败是结果，不是 HTTP 错误**：回 `200 {ok:true, check:{ok:false,error}}`，错误文本是传输层/服务器的原话，直接显示在卡片上。只有「名字不存在」这类校验失败才 `400`。
2. **只探活，不改快照**：`tools` 快照由「刷新快照」负责；检测只在工具名集合与快照不一致时报 `toolsDiffer`，卡片提示「工具已变化，建议刷新快照」。
3. **不改 `eagerConnectFailed`**：那是常驻注册在**本进程**里的状态，探活成功不代表注册已经恢复。

结果落盘到 `entry.lastCheck{at,ok,latencyMs,toolCount,serverName,toolsDiffer,error}`，所以重开页面看到的是「上次连通 · 371 ms · 2 分钟前」而不是「未检测」。前端「全部检测」并发上限 3，逐个完成即更新圆点与头部计数（连通/失败/检测中/未检测）。

错误文本会落盘再回浏览器，可能带 URL 或 header 值，所以 `entryView` 用 `scrubSecrets` 把敏感 env 值、全部 header 值、条目 URL 逐段替换成掩码（长度 <4 的值跳过，避免误伤普通词）；`reveal=1` 才给原文。

## Alternatives considered

- **复用「刷新快照」当检测**：那会顺手改写快照与服务器元信息，把「看一眼通不通」变成有副作用的写操作；而且它在条目 disabled 时直接报错，恰恰是用户最想探活的场景。
- **只做 HTTP/端口可达性检查**：实现最省，但对 stdio 条目无意义，且「端口开着」不等于 MCP 握手成功（协议版本、初始化参数、鉴权都可能失败）——假绿比没有更糟。
- **在宿主侧定时轮询探活**：能自动发现掉线，但会在后台持续拉起 stdio 子进程（有的 MCP 启动成本高），也与「启动路径只做必要且快的事」的既有纪律冲突；探活必须是人按下去的动作。
- **结果只放内存、不落盘**：省一次写盘，但刷新页面就丢，卡片回到「未检测」；用户看的是「最近一次是什么时候、结果如何」，时间戳本身就是信息。
- **把检测做成模型工具**：会让模型有多余的探活动作；这是人看界面的需求，留在 UI 路由即可。

## Consequences

- `registry.json` 增加 `lastCheck` 字段（旧条目缺该字段时 UI 显示「未检测」，无需迁移）。
- 「检测」与「刷新快照」职责分离：前者永远无副作用（除 lastCheck），后者永远会重写快照。
- 探活会真的执行条目里的本地命令（与 `setTier`/「刷新快照」同一能力类别，路由受同源 + 主机名白名单保护）。本地命令审批的「三档」只作用于**模型登记**新命令，不拦截人点「检测」——这是既有的边界，不是本次新增的豁免。
- 一次探活的失败文本可能很长（超时/协议错误），卡片里默认限高滚动、悬停看全文。
- 回归守卫：`test/mcp-check-smoke.mjs` 真起两个 stdio fixture（正常服务器 / `process.exit(3)`），断言连通结果、工具数、快照不被改写、落盘与 `GET /mcp` 回读、未知名字 400、掩码与 reveal 双向。做过故障注入验证：去掉落盘、让 scrub 直通，两处都会把该测试打红。
